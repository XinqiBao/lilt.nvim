*lilt.txt* *lilt*  Read literature through retyping in Neovim

Lilt places a reference beside an ordinary manuscript buffer. Use native editing,
undo, redo, and :write. There are no scores, automatic corrections, or autosave.
Requires Neovim 0.11 or newer. Online discovery/downloads need curl; EPUB acquisition
also needs Pandoc 3.1.1+ on PATH. PoetryDB needs only curl; local reading needs neither.

START                                                        *lilt-start*

Run :Lilt. Choose Examples, a work, and a reading unit for an offline first try.
Retype the reference, preserving its physical line and paragraph breaks.
Examples retain temporary manuscripts for this Neovim process. To keep progress
across processes, acquire a work online or add a prepared local work to the library.

COMMANDS                                                     *lilt-commands*

:Lilt          Open the library Picker. Repeated calls focus the existing Picker.
:LiltGhost     Switch an active reading to Ghost; focus its manuscript.
:LiltSplit     Switch an active reading to Split; focus its manuscript.
:LiltClose     Close the reading presentation and retain the manuscript buffer.

Ghost blends untyped reference text into your writing. Pause over a mistake in
Normal mode for a local hint. Future virtual lines cannot be searched or browsed.
Split provides a complete protected reference pane with native search/scrolling,
independent of your manuscript. Use CTRL-W commands to move and resize panes.

Manuscripts disable native automatic completion on Neovim 0.12+. Third-party
completion follows your configuration; b:lilt_manuscript identifies these buffers.

PICKER                                                       *lilt-picker*

j/k, Up/Down     Move through all text rows, including headings and metadata.
gg/G             Go to the first/last line. Counts address a specific line.
Enter, l, Right  Select an action.
h, BS, Left      Go back; close at the library page.
q, Escape        Quit the Picker from any menu.
d / a / e        Discover online / add local work / examples, from the library.
b                Browse supported categories, from Discover results.
s                Edit a catalog search while in Discover.
[ / ]            Previous / next group page; ] loads more aggregate results.
a / o            Add to library / open the local copy, from online work details.
i                Work information, from a reading-unit page.
r                Retry a failed request.

Only actions receive a cursor-line highlight and respond to Enter/l/Right.
Headings and metadata are informational; activating them does nothing. Menus
initially focus an action; information pages start at the title. Use a/o to
add/open directly. Online Work information places availability and Add/Open
before remaining metadata, source and rights. Its footer advertises the available
primary shortcut even when a long title fills the viewport. Unsupported works
do not advertise Add. Action shortcuts also appear beside their labels.
Escape inside the search or directory-name editor cancels only that input.

Works with a table of contents show its hierarchy on one page. Group headings
are informational; linked entries open ordinary units. Long chapters group their
numbered reading parts. Units absent from the table of contents remain accessible
under Other reading units. Aliases share the same manuscript and progress.

Selecting a unit automatically shows its opening reference text in a passive,
read-only preview: on the right in wide terminals, below in narrower ones, or
hidden on very small terminals. Focus stays on the list; Enter starts reading.
There is no preview mode, scrolling, or extra navigation step. Previewing creates
no manuscript and does not change progress. Remote texts are only downloaded
through Add to library.

Work information shows saved title, authors, translators, languages, subjects,
bookshelves and source identity/URL where recorded. Local directory and actual
preparation settings appear separately. Missing fields are omitted. Long fields
wrap completely and can be read with ordinary scrolling, including narrow
terminals. h/BS/Left or Back to reading units restores your selection and scroll;
q/Escape closes the entire Picker. Viewing information creates no manuscript.

Local information reads saved lilt.json metadata offline, without refreshing or
changing the work. Online details describe the current catalog and may differ
from an installed copy. When retained, the local page lists SOURCE.json's path
for the fuller acquisition catalog snapshot and the source archive path. No
snapshot age is inferred; older/imported works may lack these files.

Your works come first. Secondary actions are Discover online, Add local work,
and Examples. Add local work expects a directory containing lilt.json and UTF-8
reference files. The floating path input offers directory completion with Tab
and Shift-Tab. Enter accepts a completion; a second Enter opens the directory.
Paths may include ~ and spaces. Invalid paths remain editable with feedback;
Escape/CTRL-C cancels only the input and restores the library selection.
Library and example discovery errors wrap fully; scroll to inspect long paths
and their validation causes.
New works then offer an editable directory name, initially the official title.
The input previews normalized spelling; Enter accepts and Escape cancels. ASCII
capitals become lowercase, separators become hyphens, and source IDs are appended
when available. Collisions leave the name editable. Official titles and authors
remain in the library list; Work information shows the actual directory.
Repeated source entries open their existing copy, regardless of its directory.
See doc/works.md in the plugin checkout for the manifest format and validation.

Discover immediately opens Explore, combining participating sources in one
list. s opens Search and b opens Browse categories above results, even while
loading. The menu includes only supported categories: Explore, Poetry, Short
stories, Recently listed and Browse poets. Choosing the same category preserves
its feed without a request; changing category replaces browse. Search pushes
one layer above browse; editing its query replaces search. Back from search
restores the exact browse position; back from browse returns to the library.
Choosing a category from search returns to browse before applying it.

Search covers Gutenberg and PoetryDB; Unglue.it contributes through browsing.
Search edits a line inside the float: Enter submits, Escape/CTRL-C cancels. An
empty query preserves the page. Native insertion and editing remain available.
Load more appends a batch; Retry failed requests only failed sources and
retains successful results. Progress appears once in the footer: Loading,
Loading more for paging, or Retrying. The content heading shows Paused after
cancellation. Footer navigation adapts to width, with r retry when failed
sources can be retried and ] load when paused sources can continue. Narrow
footers prioritize these recovery actions. Returning does not resume requests
automatically. Partial results remain usable; failed searches do not
claim there are no matches. Search notes browse-only collections. No combined
total or cross-source ranking is inferred. Groups open a page titled with the
poet or work, with one official source row and full-width entries.
Next/Previous replaces only that group page. Multiple eligible downloads remain
explicit choices, not a guessed edition. Gutenberg supplies public-domain
EPUBs, Unglue.it eligible English EPUB copies with recognized rights, and
PoetryDB poems as native text with exact source rows. See doc/sources.md for
capabilities, eligibility and retained source artifacts. Wide windows show
muted Gutenberg/Unglue.it/PoetryDB hints at the right of each result's first
row; narrow windows omit them. Full titles and authors wrap; every continuation
row opens the same work. Groups marked with › expand into choices. Work
information retains official source names and exact identities. Details add one
level; back restores your result selection and scroll. A failed request offers
retry in place; back, leaving the window, or closing cancels outstanding
requests. Source-supplied descriptions, publisher/publication facts, rights and
license URLs appear when available. Source copy title and Source version record
advertised acquisition metadata, not an inferred bibliographic edition. Saved
work information reads these facts offline and lists retained original source,
catalog, attribution and license files.

SAVING                                                       *lilt-saving*

Save library manuscripts with :write. Their paths are:
    <library>/manuscripts/<work>/<unit-path>
Parents are created on write. Select the same work/unit in a later process to
resume. Percentages count saved physical rows, including blanks, against reference
rows; they do not measure correctness. Unsaved edits do not affect percentages.
A dash means no saved manuscript; ? means progress could not be read.

Closing or switching retains ordinary buffers and undo histories. Use :ls and
:buffer to find them. Modified hidden manuscripts still block an ordinary :qall.
Examples can be exported with :write /path/to/file.txt (create parents first), but
that export does not make the example resume automatically in a later process.

SETUP                                                        *lilt-setup*

No setup call is required. The library follows XDG data directory conventions
(XDG_DATA_HOME/lilt). Optional overrides: >lua
    require('lilt').setup({
      library = '~/Books/Lilt',
      -- Optional self-hosted Gutendex server:
      -- catalog = 'https://your-gutendex-server',
    })
<
Highlights respect explicit overrides and follow your colorscheme:
    LiltPending   Comment
    LiltError     DiagnosticError
    LiltExtra     DiagnosticWarn
    LiltMissing   DiagnosticUnderlineWarn

LIMITS AND SOURCES                                           *lilt-limits*

Follow physical reference rows; there is no reflow or cross-line alignment.
Keep reference files and unit paths stable after starting. Ghost may clip text
in narrow windows; Split provides wrapped reference browsing. Comparison uses
UTF-8 codepoints, not full grapheme layout.

Project Gutenberg discovery uses Gutendex (https://gutendex.com/); its literary
texts come from Gutenberg's PGLAF mirror. Public-domain status in the USA does
not establish status in your country. Acquisitions preserve the original EPUB
and credits/license in SOURCE.epub.
Review https://www.gutenberg.org/policy/license.html before sharing, including
terms for the Project Gutenberg registered trademark. Lilt is an independent
client. Details on preparation, service limits, and redistribution: doc/works.md.
Unglue.it uses published anonymous OPDS feeds (https://unglue.it/api/help).
Rights apply to the selected copy; short CC labels do not establish a license
version. SOURCE.opds retains the exact feed, SOURCE.json identifies the selected
link, and SOURCE.epub retains original notices. Read those notices before reuse.

PoetryDB (https://poetrydb.org) acquisitions retain the original full JSON response
in SOURCE.poetrydb.json and the selected record/request in SOURCE.json. Attribution
distinguishes its CC BY 4.0 curated data from primary texts it describes as public
domain. Source provenance is retained only when supplied; generated biographies
and guessed language tags are excluded. See doc/sources/poetrydb.md.
