*lilt.txt* *lilt*  Read literature through retyping in Neovim

Lilt places a reference beside an ordinary manuscript buffer. Use native editing,
undo, redo, and :write. There are no scores, automatic corrections, or autosave.
Requires Neovim 0.11 or newer. Online discovery needs curl; acquiring new works
also needs Pandoc 3.1.1+ on PATH. Local reading needs neither tool.

START                                                        *lilt-start*

Run :Lilt. Choose Examples, a work, and a reading unit for an offline first try.
Retype the reference, preserving its physical line and paragraph breaks.
Examples retain temporary manuscripts for this Neovim process. To keep progress
across processes, acquire a work online or add a prepared local work to the library.

COMMANDS                                                     *lilt-commands*

:Lilt          Open the library Picker. Repeated calls focus the existing Picker.
:LiltGhost     Switch an active reading to Ghost; focus its manuscript.
:LiltSplit     Switch an active reading to Split; focus its manuscript.
:LiltClose     Close the reading presentation and retain the manuscript buffer.

Ghost blends untyped reference text into your writing. Pause over a mistake in
Normal mode for a local hint. Future virtual lines cannot be searched or browsed.
Split provides a complete protected reference pane with native search/scrolling,
independent of your manuscript. Use CTRL-W commands to move and resize panes.

Manuscripts disable native automatic completion on Neovim 0.12+. Third-party
completion follows your configuration; b:lilt_manuscript identifies these buffers.

PICKER                                                       *lilt-picker*

j/k, Up/Down     Move through all text rows, including headings and metadata.
gg/G             Go to the first/last line. Counts address a specific line.
Enter, l, Right  Select an action.
h, BS, Left      Go back; close at the library page.
q, Escape        Quit the Picker from any menu.
d / a / e        Discover online / add local work / examples, from the library.
s                Edit a catalog search while in Discover.
[ / ]            Previous / next result page, when available.
a / o            Acquire / open the local copy, from work details.
r                Retry a failed request.

Only actions receive a cursor-line highlight and respond to Enter/l/Right.
Headings and metadata are informational; activating them does nothing. Menus
initially focus an action; online work details start at the title. Use a/o to
acquire/open directly. Action shortcuts appear beside their labels.
Escape inside the search editor cancels only that input.

Selecting a unit automatically shows its opening reference text in a passive,
read-only preview: on the right in wide terminals, below in narrower ones, or
hidden on very small terminals. Focus stays on the list; Enter starts reading.
There is no preview mode, scrolling, or extra navigation step. Previewing creates
no manuscript and does not change progress. Remote texts are only downloaded
through Acquire and read.

Your works come first. Secondary actions are Discover online, Add local work,
and Examples. Add local work expects a directory containing lilt.json and UTF-8
reference files. The native path prompt offers directory completion with Tab.
See doc/works.md in the plugin checkout for the manifest format and validation.

Discover starts with Popular (Gutenberg download order). Newest uses descending
catalog IDs; Poetry and Short stories browse popular works in those topics.
Search edits a line inside the float: Enter submits, Escape/CTRL-C cancels.
An empty query returns to Popular. Native insertion and editing remain available.
Next page and Previous page preserve the query. Changing a query, preset or page
replaces the results; back returns to the library. Details add one level and back
restores your result selection and scroll. A failed request offers retry in place;
back, leaving the window, or closing cancels outstanding requests.

SAVING                                                       *lilt-saving*

Save library manuscripts with :write. Their paths are:
    <library>/manuscripts/<work>/<unit-path>
Parents are created on write. Select the same work/unit in a later process to
resume. Percentages count saved physical rows, including blanks, against reference
rows; they do not measure correctness. Unsaved edits do not affect percentages.
A dash means no saved manuscript; ? means progress could not be read.

Closing or switching retains ordinary buffers and undo histories. Use :ls and
:buffer to find them. Modified hidden manuscripts still block an ordinary :qall.
Examples can be exported with :write /path/to/file.txt (create parents first), but
that export does not make the example resume automatically in a later process.

SETUP                                                        *lilt-setup*

No setup call is required. The library follows XDG data directory conventions
(XDG_DATA_HOME/lilt). Optional overrides: >lua
    require('lilt').setup({
      library = '~/Books/Lilt',
      -- Optional self-hosted Gutendex server:
      -- catalog = 'https://your-gutendex-server',
    })
<
Highlights respect explicit overrides and follow your colorscheme:
    LiltPending   Comment
    LiltError     DiagnosticError
    LiltExtra     DiagnosticWarn
    LiltMissing   DiagnosticUnderlineWarn

LIMITS AND SOURCES                                           *lilt-limits*

Follow physical reference rows; there is no reflow or cross-line alignment.
Keep reference files and unit paths stable after starting. Ghost may clip text
in narrow windows; Split provides wrapped reference browsing. Comparison uses
UTF-8 codepoints, not full grapheme layout.

Discovery uses Gutendex (https://gutendex.com/); literary texts come from Project
Gutenberg's PGLAF mirror. Public-domain status in the USA does not establish status
in your country. Acquisitions preserve the original EPUB and credits/license in
SOURCE.epub. Existing plain-text acquisitions retain their original SOURCE.txt.
Review https://www.gutenberg.org/policy/license.html before sharing, including
terms for the Project Gutenberg registered trademark. Lilt is an independent
client. Details on preparation, service limits, and redistribution: doc/works.md.
