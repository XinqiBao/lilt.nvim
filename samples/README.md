# Literary sample

This directory is a Lilt work: `lilt.json` declares one reading unit. The `:Lilt`
example opens a temporary manuscript and never writes into this directory. Add
this directory as a local work to keep a personal manuscript in your library.

`alice.txt` contains an excerpt from Lewis Carroll (Charles Lutwidge Dodgson,
1832–1898), *Alice's Adventures in Wonderland* (1865), Chapter I,
“Down the Rabbit-Hole.” The original work is in the public domain in the United
States and in countries with a life-plus-70-year copyright term.

[Project Gutenberg ebook 11](https://www.gutenberg.org/ebooks/11) provides the
complete work and bibliographic context. The exact transcription source of this
repository's original sample was not recorded; this link identifies the work,
not a claimed source edition for this file.

The passage is prepared with UTF-8 punctuation and physical lines of at most
74 display columns. Preserve its line layout: existing manuscripts compare by
physical row. The plugin's MIT code license does not change the literary text's
copyright status.
